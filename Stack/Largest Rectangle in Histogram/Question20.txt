Question 20 : You are given an array of integers heights where heights[i] represents the height of a bar. The width of each bar is 1.

Return the area of the largest rectangle that can be formed among the bars.



Input: heights = [7,1,7,2,2,4]

Output: 8


Input: heights = [1,3,7]

Output: 7


Constraints:

1 <= heights.length <= 100,000.
0 <= heights[i] <= 10,000
